## 2. Վաճառք, զեղչ, վերադարձ
| № | Հարց | Պատասխան |
|---|---|---|
| 2.1 | Զեղչը ՀԾ-ում առանձին սյունա՞կ է, թե արդեն հանված է գնից | ☐ Առանձին ☐ Հանված |
| 2.2 | Վերադարձը գրանցվում է ☐ առանձին փաստաթղթով ☐ բացասական տողով ☐ երկուսն էլ | |
| 2.3 | Վերադարձը վերագրել ☐ վաճառքի ամսվան ☐ վերադարձի ամսվան | Լռելյայն՝ վերադարձի ամսվան, վաճառքի ամիսը նշելով |
| 2.4 | Նվեր/պրոմո ապրանք (0 գին)՝ ☐ վաճառք է ☐ մարքեթինգային ծախս | |
| 2.5 | Կլորացում՝ ☐ տողով ☐ փաստաթղթով; ☐ 0 ☐ 2 տասնորդական | |

|---|---|---|
| 3.1 | Պաշարի գնահատման մեթոդ՝ ☐ FIFO ☐ միջին կշռված ☐ կոնկրետ պարտիա ☐ այլ | |
| 3.2 | Ինքնարժեքը ներառում է ☐ միայն գնման գին ☐ + առաքում/մաքսատուրք ☐ + այլ | |
| 3.3 | Ինքնարժեքն առկա՞ է յուրաքանչյուր SKU-ի համար ՀԾ-ում | ☐ Այո ☐ Մասամբ ☐ Ոչ → ձեռքով top-50 |
| 3.4 | Պահեստի մնացորդը հաշվի է առնում ☐ ռեզերվացված ☐ ճանապարհին ☐ միայն ֆիզիկական | Լռելյայն՝ ֆիզիկական |
