## Выводы
1. **Файловый MVP покрывает все P0-источники**, кроме Instagram и Telegram (там ручной ввод, как и планировалось).
2. Самая зрелая API-интеграция — **ՀԾ-Առևտուր**: хорошая документация, предсказуемые лимиты. Единственный gate — тариф клиента. Это кандидат на «один read-only API» фазы 2.
3. **Банковский API для SaaS не подтверждён ни одним банком.** Решение: выписка клиента сейчас; вопросник банкам отправить в фазе 0 параллельно, без ожидания.
4. Две ссылки документа устарели: тариф Ameriabank (есть ред. 03.07.2026) и редакция закона о ПД (актуальна acts/229131). Обновить документ основателя.
