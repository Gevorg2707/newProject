# Банки Армении, ЦБ РА, закон о персональных данных, AgencyAnalytics

## Ameriabank — FACT
- Тариф из документа основателя (ред. 42 от 03.04.2026) **устарел**. Актуальная редакция: https://ameriabank.am/Portals/0/files/Business/green/Corporate_tariffs_03.07.26_eng.pdf (действует с 03.07.2026).
- §2 п. 7.2: «Internet Banking API for business» — **40 000 AMD в год**. Сноска: сервис позволяет клиенту выполнять/отправлять запросы **со своего IP-адреса по частному каналу, предоставленному банком**.
- П. 8.4: SWIFT **MT940** — 1 000 AMD за документ, с НДС. П. 8.1: выписки до 1 года в электронном виде — бесплатно; п. 8.8.1: доставка выписки электронно — бесплатно.
- vPOS help (servicestest.ameriabank.am/VPOS/help): только контроллер VPOS, 12 POST-методов: InitPayment, GetPaymentId, GetPendingTransactions, ConfirmPayment, GetPaymentDetails, RefundPayment, CancelPayment, GetBindings, Activate/DeactivateBinding, MakeBindingPayment, SSNCheck. **Нет остатков и выписок.** Подтверждает тезис: vPOS ≠ API счёта.
- Публичной документации корпоративного API (остаток/выписка) **не найдено**. ASSUMPTION: API выдаётся двусторонне, с IP-allowlist и доками по договору. Для SaaS с несколькими tenant это означает отдельный договор на каждого клиента или партнёрство с банком.

## Решение по банкам (рекомендация)
**Сейчас: импорт выписки, выгруженной клиентом (CSV/XLSX из интернет-банка; MT940, если клиент готов платить 1 000 AMD/документ).** Прямой API — только по письменному техническому и договорному ответу банка. Банковский остаток показывать с источником и временем; при устаревании — «последний известный остаток». Никакого сбора паролей, scraping и неофициальной автоматизации.

## Закон о персональных данных — FACT
- Действует закон РА «О защите персональных данных» **ՀՕ-49-Ն от 18.05.2015** (в силе с 01.07.2015). Ссылка из документа (acts/218690) — редакция 04.01.2026–15.08.2026, **устарела**. Актуальная консолидированная: https://www.arlis.am/hy/acts/229131 (с 15.08.2026).
- Поправки: ՀՕ-447-Ն от 04.12.2025 (в силе 04.01.2026; исключены ч. 4,5,9 ст. 19, ч. 1 ст. 22, п. 7 ч. 3 ст. 24; технические требования безопасности перенесены к автономному органу по закону о публичной информации) и ՀՕ-191-Ն от 07.05.2026 (ст. 25, в силе 15.08.2026).
- **Ст. 5 (соразмерность):** законная цель, пригодные/необходимые/умеренные средства, минимум данных; запрещена обработка данных, не нужных цели; запрещена, если цель достижима обезличенными данными; хранение в идентифицируемом виде не дольше необходимого.
- **Ст. 27 (передача в другие государства):** с согласия субъекта или если следует из цели обработки (27.1); без разрешения органа — только в страны с «адекватным уровнем» (международные договоры или список органа) (27.2); в прочие — с разрешения органа по договору с гарантиями, заявка письменно, решение 30 дней (27.3–27.4). Список адекватных стран: решение ԱՏՊՀ-001/24 от 08.07.2024, https://www.arlis.am/hy/acts/195045.
- **Ст. 23:** уведомление органа добровольно; обязательно по требованию органа и **до обработки биометрических/особых данных**.
- Нового закона взамен 2015 года **нет**. Пакет реформы (закон о Комиссии по защите ПД, DPIA/DPO) опубликован на e-draft.am (проект 10533) в августе 2026 — **ПРОЕКТ**, статус дальше UNVERIFIED.

### Следствия для продукта (ASSUMPTION до юриста)
- Не импортировать PII покупателей (отсекать на mapping) → ст. 5 выполняется по построению.
- Контрагенты в выписке: псевдонимизировать/маскировать до хранения.
- LLM-провайдер за рубежом: передавать только агрегаты и товарные данные; проверить страну провайдера по списку ԱՏՀ-001/24; иначе разрешение органа.
- Уведомление органа: не обязательно для нашего набора данных, но решение зафиксировать с юристом.
