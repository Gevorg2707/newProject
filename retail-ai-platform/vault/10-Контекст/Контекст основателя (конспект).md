# Контекст основателя (конспект)

Полный документ на армянском: `docs/CLAUDE_RETAIL_AI_PLATFORM_CONTEXT_HY.md`. Здесь конспект на русском для работы.

## Цель
B2B-сервис, затем SaaS для малой и средней розницы Армении: **рост прибыльных продаж** через аналитику и проверяемые рекомендации. Не обещаем рост, обещаем качество решений и измеримый эффект экспериментов.

## Жёсткие ограничения
- Наличный бюджет: **до $1 000**. Не включает время основателя и заказную разработку.
- Основатель: опыт QA automation, API, БД, координация тех. проектов. Java ржавая, TS/JS новичок.
- **Главное решение:** сначала **экспорт файлов клиентом + импорт в платформу**. Никаких обязательных API в первой продаваемой версии. Автоматизация, когда файловый путь докажет готовность платить.
- Сегмент первых клиентов: **розница** с SKU, продажами, себестоимостью, складом, рекламой.
- Есть HTML-прототип «Առևտրաչափ» (демо-цифры, без API). В этой сессии его нет.

## Продуктовое обещание
Одно место: продажи, товарная прибыль, склад, маркетинг, cash flow, статус сверки с бухгалтерией. Рекомендации: что пополнить, что протестировать в рекламе, что пересмотреть, что спросить у бухгалтера. Каждая рекомендация показывает расчёт, период, источники, свежесть данных, пропуски, уверенность, ответственного.

## Роли
Владелец, бухгалтер/финансист, маркетолог, склад/закупки, юрист (позже), админ платформы. Подробно: [[Роли и сценарии]].

## Первый сценарий
Клиент даёт 90 дней продаж и возвратов, коды SKU и себестоимость, остатки склада, экспорт рекламных расходов, опционально банковскую выписку. Система импортирует, валидирует, сверяет, показывает ошибки, считает KPI, выдаёт 2–3 рекомендации. Человек решает. Потом измеряется результат.

## Порядок фаз (гипотеза основателя, подлежит критике)
0. 1–2 нед.: 5 интервью, выбор одного POS/ՀԾ, образцы экспортов, 2 платных пилота.
1. 2–4 нед.: CSV/XLSX импорт, SKU mapping, экран ошибок, KPI, 2–3 рекомендации, недельный отчёт. Допустима ручная проверка.
2. 1–3 мес.: аккаунты, роли, повторяющийся импорт, сверка выписки. Решить, какой **один** read-only API окупается.
3. 3–6 мес.: read-only ՀԾ или Meta, Shopify/Woo/TikTok по запросу, трекинг экспериментов, self-service. Банк только после письменного согласия банка.
4. 6–12 мес.: EN/RU, мультивалюта, Xero/QBO, первый зарубежный клиент. Локальная LLM только после измерений.

## Бизнес-гипотеза цен (не проверено рынком)
Подключение 120–250 тыс. AMD, ежемесячно 79–149 тыс. AMD. Маркетинг-менеджмент и юрист отдельно.
