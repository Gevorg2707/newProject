# Роли и сценарии

| Роль | Видит | Может |
|---|---|---|
| Владелец / директор | KPI, выручка, покрытие (contribution), последний известный остаток банка, риски | Утвердить план действий, назначить ответственного, измерить результат |
| Бухгалтер / финансист | Продажи, возвраты, COGS, расходы, сверка счетов и банка | Утвердить правила расчёта, закрыть месяц, объяснить расхождения |
| Маркетолог | Расход по каналу/кампании/группе товаров, размеченные заказы | Спроектировать и утвердить ограниченный эксперимент; включать рекламу только по отдельному полномочию |
| Склад / закупки | SKU, остаток, скорость продаж, открытые заказы | Проверить рекомендацию пополнения и срок поставки |
| Юрист (позже) | Проект договора, условия обработки данных, рекламные обещания | Комментировать и утверждать юридический текст |
| Админ платформы | Здоровье подключений, оплата, тех. события | Минимально необходимый доступ с аудитом |

## Файловый импорт — шаги (из документа)
1. Гайд по источнику на 1 страницу: откуда, за какой период, формат, минимальные колонки. **Не выдумывать UI-шаги ՀԾ/Meta/банка, проверять в версии клиента.**
2. Принимать CSV/XLSX, для банка также MT940. Хранить исходный файл ограниченный срок, дату импорта, hash, импортёра. OCR из PDF/фото не в MVP.
3. Предпросмотр + column mapping: order id, дата/время, SKU, кол-во, чистая цена, скидка, возврат, себестоимость, склад, кампания/расход, банковская транзакция id/сумма/валюта/остаток. Отдельно: НДС включён?
4. Проверки: дубли, пропуски, валюта, несовпадающие SKU. Повторная загрузка того же файла не удваивает продажи (идемпотентность по hash + source_record_id).
5. Первый импорт ~90 дней, далее еженедельный экспорт. Всегда показывать время последнего обновления по источнику.
6. Нет экспорта из соцсети → ручной ввод с пометкой «введено вручную». Нет банковского файла → не показывать «текущий остаток».

## Что помечено как MVP (P0) по источникам
- ՀԾ-Առևտուր 9 и ՀԾ-Հաշվապահ 9: CSV (P0), read-only API (P1/P2).
- Meta Ads / Instagram: экспорт (P0), API (P1/P2).
- TikTok: экспорт (P0), API (P2).
- Telegram: вручную (P0), stats API условно (P3).
- Банк: выписка CSV/XLSX/MT940 (P0). Прямой API банка: P3, только через партнёрство.
- Shopify/Woo: P2 (международка). Xero/QBO: P3.
- vPOS: только по потребности клиента, **это не API остатка счёта**.
