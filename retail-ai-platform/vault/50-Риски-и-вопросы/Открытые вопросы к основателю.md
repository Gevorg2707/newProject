# Открытые вопросы к основателю

Только то, что меняет направление.

1. **Язык стека: TypeScript (как в документе) или Java 25 + Spring Boot?** Java совпадает с твоей целью прокачать backend и с уже знакомым тест-стеком. TS даёт один язык на UI и API, но ты в нём новичок. Моя рекомендация: Java-бэкенд + минимальный серверный UI (HTMX), React отложить. Нужно твоё решение.
2. **Готов ли ты продавать первые 2 пилота без UI** (Excel/PDF-отчёт + разбор), пока ядро импорта пишется? Это сдвигает первую оплату на недели раньше.
3. **Есть ли уже доступ хотя бы к одному реальному экспорту** (ՀԾ, Meta, банк) от знакомой розничной компании? Без реальных файлов проектировать mapping вслепую рискованно.
