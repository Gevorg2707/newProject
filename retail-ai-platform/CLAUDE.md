# Retail AI Platform — правила работы для Claude

Источник истины по продукту: `docs/CLAUDE_RETAIL_AI_PLATFORM_CONTEXT_HY.md` (контекст основателя, дата проверки фактов 2026-09-29).
Рабочие заметки и документация: Obsidian vault в `vault/`.

## Обязательные правила
- Каждое существенное утверждение помечать: **FACT** (ссылка + дата проверки) / **ASSUMPTION** / **UNVERIFIED** / **CONDITIONAL**.
- Не выдумывать версии, цены, API, разрешения вендоров. Нет источника — статус UNVERIFIED.
- Приоритет основателя: сначала файловый импорт (CSV/XLSX/MT940), API-интеграции только как следующая фаза и только read-only.
- Никогда: сбор паролей интернет-банка, screen scraping банков, автономные действия агентов с деньгами/рекламой.
- Multi-tenant: `tenant_id` в каждой сущности, проверка tenant на сервере, агентам без свободного SQL.
- Банковский остаток показывать только с источником и временем; устаревший — «последний известный остаток».
- Деливераблы для основателя: язык основателя (армянский) по запросу из раздела 13; рабочие заметки в vault — на русском, термины на английском.

## Стек (фаза 1, факт)
Java 25 + Spring Boot 4.1 (JdbcClient, Flyway), PostgreSQL 16 с RLS (`FORCE ROW LEVEL SECURITY`, роль без BYPASSRLS), Apache POI / Commons CSV, Anthropic Java SDK (выключен по умолчанию). Пилот — CLI без UI (`app/`, `docs/PILOT_RUNBOOK.md`). Без Kubernetes/GPU/микросервисов до доказанной необходимости.
- Тесты: `cd app && mvn test` (нужен локальный PostgreSQL, см. `app/README.md`); приложению нужен `DB_PASSWORD`.
- Ревью кода и статусы находок: `vault/50-Риски-и-вопросы/Ревью кода 2026-10.md`.
